# Sanskriti Canvas Website

Clean, responsive static website for the Sanskriti Canvas Indian heritage project.

## Pages
- `index.html` — Home
- `explore.html` — Explore / Coming Soon
- `about.html` — About
- `contact.html` — Contact

## Assets
Only the supplied project images are used:
- `assets/images/heritage-hero.png`
- `assets/images/logo-full.png`
- `assets/images/logo-mark.png`

## Run
Open `index.html` directly in a browser. No build step is required.
